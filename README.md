# SpearSMP starter project

This is a small Paper plugin starter project with a GitHub Actions workflow.

## Build it
1. Extract this ZIP.
2. Upload the CONTENTS of this folder to your GitHub repository (keep `.github/workflows/build.yml`).
3. Open the repository's Actions tab.
4. Run **Build SpearSMP** (or push a commit).
5. Download the `SpearSMP-build` artifact. It contains `SpearSMP-1.0.0.jar`.

## Important
This is a compiling starter prototype, not the finished SpearSMP gameplay system. Kill progression, persistent player data, special abilities, custom item models, and full anti-drop/anti-duplication protection still need to be implemented. The resource pack ZIP is a separate visual starter and is not yet automatically connected to the plugin.
